# AI SDLC Demo

This project is a demonstration of an **AI-led Software Development Lifecycle (AI SDLC)** — an approach where AI agents actively participate in each stage of building software, rather than acting only as a coding assistant.

## What "AI SDLC" means here

Traditionally, the software development lifecycle (specifying requirements, planning the work, writing code, testing, reviewing, and deploying) is carried out by people, with tools helping along the way. An AI-led SDLC flips the emphasis: AI agents drive much of that lifecycle end-to-end, while humans set direction, review outcomes, and make key decisions.

In practice, that looks like:

- Starting from a plain-language description of what needs to be built.
- Having an agent break that description down into a concrete plan and set of tasks.
- Letting an agent implement the work, run tests, and prepare the result for review.
- Giving humans clear checkpoints to review, comment, and request changes.
- Having agents pick up that feedback and iterate, until the work is ready to ship.

The goal isn't to remove people from the process — it's to let AI agents handle the repetitive, well-defined mechanics of building software, so humans can focus on intent, judgment, and quality.

## Purpose of this repo

This repository exists to explore and demonstrate what an AI-led SDLC looks like in practice: how work moves from an initial idea to a finished, reviewed, deployable result when AI agents are responsible for driving that process.
