# Task Tracker — Frontend

React + TypeScript + Vite. See `/specs/001-task-management/quickstart.md` for full context.

## Setup

```
npm install
cp .env.example .env   # then set VITE_API_BASE_URL if the backend isn't at localhost:8000
```

## Run

```
npm run dev
```

## Build

```
npm run build
```
