## Documentation policy

When a change alters how this project is built or used by contributors — new or changed
`.claude/agents` or `.claude/skills`, new scripts, new workflows, new significant
dependencies, or any other structural change a developer would need to discover — update the
relevant documentation (`README.md` by default; a more specific doc under `docs/` if one
already covers that area) as part of the same change, without being asked. Skip this for
routine code changes, bug fixes, or anything already self-evident from the code itself.
